# Свежая кровь

**Сценарий: отряд вырос с пяти до восьми за две недели.** Трое новых, план — двенадцать за год.

На что смотреть:

- **Погода откатилась к forming.** Дальний маршрут в дымке, хотя месяц назад отряд шёл уверенно.
- **Отряд.** С двумя новичками 1on1 не было ни разу. До троих старых руки не дошли: их контекст устарел, пока всё внимание уходило на новых.
- **Сигналы.** База держится на одном Феде с нагрузкой 88%, и он же полдня её объясняет. Инфраструктуру держит один Борис.
- **Карта.** Шардирование стоит, правила никто не ведёт, Надя отвечает за три перехода и ведёт троих новичков.
- **Внимание командира.** Четыре хода подряд на потолке, и всё ушло на людей: на маршрут — ноль.
- **Квесты новичков** и заметки на полях в слое «только ты».

```bash
sv web --dir examples/svezhaya-krov --today 2026-11-13
sv map --dir examples/svezhaya-krov --today 2026-11-13
sv signals --dir examples/svezhaya-krov --today 2026-11-13
```

Команда вымышленная. Если начать в папке ход, файлы изменятся; вернуть их: `git checkout examples`.
