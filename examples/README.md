# Примеры

Семь вымышленных команд. На них идут тесты, и на них удобно смотреть, как игра показывает разные положения дел. Все примеры собраны под одну дату — 13 ноября 2026 года, поэтому запускай их с `--today 2026-11-13`; пример с Jira — с `--today 2026-11-14`.

```bash
sv web --dir examples/this-is-fine --today 2026-11-13
sv map --dir examples/this-is-fine --today 2026-11-13
```

| Папка | Отряд | О чём |
|---|---|---|
| [`demo`](demo) | 5 человек, 2 агента | Исходный пример из макетов: всего понемногу |
| [`kak-po-maslu`](kak-po-maslu) | 6 человек, 2 агента | **Всё очень хорошо.** Сигналов нет, карта чистая, видно вершину |
| [`this-is-fine`](this-is-fine) | 7 человек, 3 агента | **Всё очень плохо.** Три шторма, протухший контекст, внимание на потолке |
| [`ezhik-v-tumane`](ezhik-v-tumane) | 5 человек, 2 агента | Поиск продукта: почти вся местность — туман, у переходов есть разведки |
| [`agenty-razberutsya`](agenty-razberutsya) | 5 человек, 6 агентов | Агентов больше, чем людей: линтер RACI и узкое место в проверке |
| [`svezhaya-krov`](svezhaya-krov) | 8 человек, 2 агента | Отряд вырос с пяти до восьми: погода forming, новички без контекста |
| [`jira-pomnit-vse`](jira-pomnit-vse) | 5 человек, 2 агента | Игра сверяется с Jira и Confluence: застой, расхождения, нагрузка, устаревшие страницы |

В каждой папке лежит `README.md` с тем, на что смотреть.

Если начать в примере ход, его файлы изменятся. Вернуть их: `git checkout examples`.
