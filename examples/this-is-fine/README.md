# This is fine

**Сценарий: всё очень плохо.** Семь человек и три агента. Бета должна была выйти 1 октября.

На что смотреть:

- **Сигналы.** Два критических: платежи и прод держатся каждый на одном человеке с нагрузкой от 95%. Проверку результата, железо и работу с данными не держит никто.
- **Контекст протух.** С двумя людьми 1on1 не было ни разу, с остальными — от трёх до шести недель назад. Твой собственный лист не обновлялся с сентября.
- **Карта.** Три шторма сразу, самому старому четвёртая неделя. Два перехода стоят, два никто не ведёт. Отряд не сдвинулся от лагеря ни на шаг.
- **RACI.** За два перехода отвечают агенты, за четыре — один человек.
- **Внимание командира.** Пять ходов подряд на потолке с перерасходом, на маршрут — ноль.
- **Листы Вики и Кости** в слое «только ты»: обещания, которые не закрыты.

```bash
sv web --dir examples/this-is-fine --today 2026-11-13
sv map --dir examples/this-is-fine --today 2026-11-13
sv signals --dir examples/this-is-fine --today 2026-11-13
```

Команда вымышленная. Если начать в папке ход, файлы изменятся; вернуть их: `git checkout examples`.
