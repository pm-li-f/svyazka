# Как по маслу

**Сценарий: всё очень хорошо.** Шесть человек и два агента идут к лагерю «Первые платящие». Четыре перехода из шести позади.

На что смотреть:

- **Сигналов нет.** Контекст о каждом свежий, у каждого навыка есть дублёр, нарушений RACI нет.
- **Карта чистая.** Погода performing: видно весь маршрут до вершины. Впереди один перевал и одна тропа.
- **Внимание командира** почти наполовину уходит на маршрут, а бюджет держится на шести из десяти.
- **Состав** совпадает с планом, все роли из своего списка закрыты. Список ролей отряд задал сам в `config.yaml`.

```bash
sv web --dir examples/kak-po-maslu --today 2026-11-13
sv map --dir examples/kak-po-maslu --today 2026-11-13
sv signals --dir examples/kak-po-maslu --today 2026-11-13
```

Команда вымышленная. Если начать в папке ход, файлы изменятся; вернуть их: `git checkout examples`.
