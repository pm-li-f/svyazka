# Агенты разберутся

**Сценарий: агентов больше, чем людей.** Пять человек и шесть агентов. Рутина едет быстро, но всё упирается в проверку.

На что смотреть:

- **Отряд.** Агенты стоят в общем списке: у каждого есть человек, который за него отвечает, и давность последнего отчёта.
- **RACI.** Линтер ловит два перехода, за которые отвечает агент, и Иру, которая отвечает за три сразу.
- **Сигналы.** Критический: проверку результата держит один человек с нагрузкой 91%. Это и есть потолок конвейера.
- **Слово агентам.** `agent/migrator` третью неделю ждёт подтверждения. `agent/tester` сам говорит, что его тесты ничего не проверяют. `agent/docs` молчит.
- **Карта.** Почти сплошные тропы и один перевал, который стоит, потому что агент не может получить «да».
