# Ёжик в тумане

**Сценарий: поиск продукта.** Пять человек и два агента ещё не знают, что строят. Почти вся местность — туман.

На что смотреть:

- **Карта.** Пять переходов из семи — туман. Цикл на этапе «маршрут»: дальние лагеря названы, но путь к ним не проложен.
- **Разведки.** У каждого туманного перехода есть гипотезы и выводы по ним. Это и есть журнал гипотез: файлы в `team/tasks/`.
- **Слово агентам.** Отчёт `agent/scribe` меняет гипотезу: говорят про отчёты, а не про интеграции.
- **Внимание командира** больше чем наполовину уходит на маршрут. Для этого этапа это нормально.
- **Лист Аркадия.** Человеку, которому нужен план, в тумане неуютно: контекст о нём устарел, квест стоит.

```bash
sv web --dir examples/ezhik-v-tumane --today 2026-11-13
sv map --dir examples/ezhik-v-tumane --today 2026-11-13
sv signals --dir examples/ezhik-v-tumane --today 2026-11-13
```

Команда вымышленная. Если начать в папке ход, файлы изменятся; вернуть их: `git checkout examples`.
