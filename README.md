# Связка

Экспедиция продуктовой команды: инструмент CPTO для управления небольшой IT-командой в форме игры. Первая версия — для одного человека, данные лежат локально.

Сейчас готов нулевой шаг: схема данных, загрузчик и пример.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run check
```

`check` проверяет типы, прогоняет тесты и валидирует пример данных.

## Папка игры

Состояние игры — папка с Markdown и YAML. Слой видимости задаётся папкой.

```
team/                 видит отряд
  people/<id>.md      кто, роль, тип, ремесло
  agents/<id>.md      агент, кто за него отвечает, его отчёты
  tasks/<id>.md       переход: местность, статус, RACI, разведки
  map.yaml            лагеря, этап цикла, погода
pair/<id>/            человек и CPTO
  sheet.md            состояние, оценки, квест, темы 360
  journal.md          встречи
me/<id>.md            только CPTO: связи, заметки на полях
turns/<дата>.md       ход: внимание, действия, решения, что не успел
config.yaml           срок годности, внимание, модель штурмана
```

Данные в Markdown-файлах лежат в YAML-шапке между строками `---`; ниже шапки можно писать свободные заметки. Файлы удобно править руками, в том числе в Obsidian.

Проверить свою папку:

```bash
npm run validate -- путь/к/папке
```

## Пример

`examples/demo` — вымышленная команда из макетов: пять человек, два агента, шесть переходов. В данных намеренно оставлены нарушения, которые на следующем шаге должен находить линтер: переход, за который отвечает агент; переход, который никто не ведёт; человек, отвечающий за три перехода сразу.
